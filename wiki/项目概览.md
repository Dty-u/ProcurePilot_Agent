# 项目概览

ProcurePilot Agent 是面向企业采购的智能助手，基于 `DeepAgents==0.4.12`，通过主 Agent 和专业子 Agent 完成采购查询、供应商比价、分析报告和采购订单操作。

项目不是让 LLM 直接操作数据库。Python 业务层负责确定性规则和数据，MCP 提供受控工具，Agent 负责理解、规划和编排，订单写操作必须由人审批。

## 核心技术

- Python 解释器：`D:\py_venv\harness_agent\Scripts\python.exe`（Python 3.10.10）。
- Agent：DeepAgents、LangGraph、主/子 Agent、中间件、HITL。
- 接入：FastAPI + SSE。
- 工具：MCP Server 暴露 Python 采购业务能力。
- 执行隔离：OpenSandbox。
- 持久化：业务数据库、checkpoint、用户 Memory 和展示历史相互分离。

## MVP 范围

- 供应商、物料、报价、库存和采购订单的 Python 业务能力。
- `procurement-analyst`：查询、比价、分析、图表和报告。
- `procurement-order`：订单信息补充、人工审批和审批后执行。
- SSE 流式内容、工具事件、中断与恢复。
- 用户偏好、Skills 和沙箱产物管理。

暂不包含真实 ERP、支付、无人审批自动下单，以及没有明确需求的 Redis、向量数据库或知识图谱。
