# 数据模型

本文是概念模型，不是已落库的 DDL。

## 业务模型

| 模型 | 核心字段 |
| --- | --- |
| `Supplier` | `supplier_id`、`supplier_code`、`name`、`status`、质量/交付指标、`version` |
| `Part` | `part_id`、`part_code`、`name`、`specification`、`unit`、`status` |
| `SupplierQuotation` | `quotation_id`、`supplier_id`、`part_id`、`unit_price`、`currency`、起订量、交期、有效期、来源、采集时间 |
| `InventoryItem` | `inventory_id`、`part_id`、`warehouse_code`、现有量、预留量、安全库存、`version` |
| `PurchaseOrder` | `order_id`、`order_no`、`supplier_id`、`status`、`currency`、`total_amount`、审批信息、`idempotency_key`、`version` |
| `PurchaseOrderItem` | `order_item_id`、`order_id`、`part_id`、数量、单位、单价、行金额、报价引用 |
| `OperationAudit` | `audit_id`、`trace_id`、用户、动作、对象、参数摘要、审批、结果和时间 |

金额和数量使用 `Decimal`，时间使用带时区的 `datetime`，有限状态使用枚举。订单总额和行金额由业务层计算，写入使用幂等键和乐观锁。

## Agent 上下文

`ProcurementContext` 只保存运行所需的最小信息：`user_id`、`username`、`thread_id`、`trace_id`、已鉴权角色、语言和时区。密钥、连接串和完整历史不得进入上下文。

## 存储职责

| 数据 | 主键/作用域 | 用途 |
| --- | --- | --- |
| 业务数据 | 业务 ID | 权威业务事实 |
| checkpoint | `thread_id` | 恢复 Agent 执行和中断点 |
| 展示消息 | `thread_id + message_id` | 前端会话回放 |
| 用户偏好 | `user_id` | 跨会话语言、币种、图表等偏好 |
| 沙箱文件 | sandbox ID + path | 临时分析、脚本、图表和报告 |
| 持久化 Skill | scope + name + version | 已审核技能恢复 |

用户偏好可包含 `preferred_output`、`preferred_chart_type`、`preferred_currency`、`preferred_language`，以及有限数量的近期供应商和查询。不得自动保存敏感属性。
