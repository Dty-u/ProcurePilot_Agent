# M4 MCP 工具层 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已测试的采购 Service 暴露为具有稳定 Schema、权限上下文和错误语义的 MCP 工具。

**Architecture:** MCP 是协议适配层，不承载采购规则。工具从可信上下文获取调用者信息，调用 Service 后统一映射为 `ToolEnvelope`；MCP Server 使用异步工厂和 lifespan 初始化依赖。

**Tech Stack:** MCP Python SDK、Pydantic v2、asyncio、pytest、MySQL Service

---

## 前置条件

- M3 Repository 和集成测试通过。
- 第一轮只实现只读工具；写工具的安全实现放到 M6。

### Task 1: 工具信封与错误映射

**Files:**
- Create: `src/mcp_server/__init__.py`
- Create: `src/mcp_server/schemas.py`
- Create: `src/mcp_server/error_mapper.py`
- Modify: `pyproject.toml`
- Test: `src/tests/unit/mcp_server/test_tool_envelope.py`

`mcp_server` 是 `src/` 下与 `procurepilot` 并列的独立 Python 包。将其加入 wheel 包清单；业务类型和 Service 继续从 `procurepilot.business` 导入。

定义泛型 `ToolEnvelope[T]` 和 `ToolError`：

```text
ToolEnvelope: ok, data, error, trace_id
ToolError: code, message, retryable
```

映射固定错误码：`VALIDATION_ERROR`、`NOT_FOUND`、`CONFLICT`、`PERMISSION_DENIED`、`APPROVAL_REQUIRED`、`DEPENDENCY_TIMEOUT`、`INTERNAL_ERROR`。内部异常只记录关联 trace_id，客户端不接收堆栈、DSN、文件路径或密钥。

### Task 2: 可信调用上下文

**Files:**
- Create: `src/mcp_server/context.py`
- Test: `src/tests/unit/mcp_server/test_context.py`

定义 `ToolCallerContext(user_id, roles, trace_id)`。MCP Tool 的业务参数中不得出现可覆盖身份的 `user_id` 或 `roles`。上下文缺失、角色无效或 trace_id 非法时失败关闭。

### Task 3: 六个只读工具

**Files:**
- Create: `src/mcp_server/tools/__init__.py`
- Create: `src/mcp_server/tools/suppliers_tools.py`
- Create: `src/mcp_server/tools/parts_tools.py`
- Create: `src/mcp_server/tools/inventory_tools.py`
- Create: `src/mcp_server/tools/order_tools.py`
- Test: `src/tests/contract/test_read_tools.py`

实现并保持名称稳定：

```text
supplier_query
part_query
part_by_supplier
quotation_query
inventory_warning
order_search_details
```

每个工具使用严格 Pydantic 参数模型、明确分页上限和查询超时。`quotation_query` 返回 quotation ID、来源、采集时间、有效期、MOQ、币种和单位；`order_search_details` 需要订单读取角色并返回 version。

契约测试使用 Fake Service，验证参数、工具名、成功信封、错误映射、超时和结果限长。

### Task 4: MCP Server 生命周期

**Files:**
- Create: `src/mcp_server/server_main.py`
- Create: `src/mcp_server/__main__.py`
- Test: `src/tests/integration/test_mcp_server.py`

通过 `create_mcp_server(settings, service_container)` 工厂注册工具。模块导入不创建 engine、不连接 MySQL。启动时创建资源，关闭时释放。传输方式和端口由配置决定，默认端口不得与 FastAPI 端口共用。
