# Python 编码规范

- 公共函数、方法和数据模型使用类型标注，命名表达业务含义。
- 领域逻辑、协议适配、配置和基础设施分层，不在 Prompt 或 MCP 中重复业务规则。
- 外部输入使用 Pydantic 校验；金额用 `Decimal`，时间用带时区的 `datetime`，状态使用枚举。
- FastAPI、LLM、MCP、数据库和沙箱 I/O 使用异步接口并设置超时；运行中的事件循环内禁止调用 `asyncio.run()`。
- 不使用裸 `except:`；业务错误、基础设施错误和协议错误应可区分。
- 工具返回稳定结构：`ok`、`data`、`error`、`trace_id`，失败时不得伪造成功。
- 日志至少关联 `trace_id`、`thread_id`、脱敏用户标识、Agent 和工具名，不记录 Prompt 全文及敏感数据。
- 配置集中管理；提交 `.env.example`，不得提交 `.env` 或密钥。
- 工具名称稳定且唯一，读写工具分权；子 Agent 只获取必需工具。
- 大型工具结果写入沙箱文件，只返回摘要和文件引用。
- 文件、函数、变量用 `snake_case`，类用 `PascalCase`，常量用 `UPPER_SNAKE_CASE`。
- 测试文件使用 `test_<module>.py`，测试名应说明场景和预期结果。
