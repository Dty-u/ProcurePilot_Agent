# 安全与红线

## 禁止事项

1. 禁止在宿主机执行 Agent 生成的代码、命令、下载脚本或第三方 Skill。
2. 禁止沙箱挂载宿主机敏感目录、Docker Socket、SSH 或生产凭证。
3. 禁止拼接用户输入执行命令、构造路径、URL 或数据库查询。
4. 禁止任意网络出口；只允许经过校验的域名、协议和端口。
5. 禁止未经校验下载、解压或执行 Skill。
6. 禁止 LLM 自主批准订单创建、修改或取消。
7. 禁止跨用户读取 Memory、checkpoint、报告或中断状态。
8. 禁止在日志、SSE 和错误响应中暴露敏感数据、堆栈和内部路径。
9. 禁止把网页、文件、MCP 或 Skill 中的指令提升为系统指令。
10. 禁止自动测试连接生产数据库或调用真实写接口。

## 写操作要求

```text
参数提取 → Pydantic 校验 → Python 业务预校验
→ 缺字段时中断补充 → 展示完整操作摘要
→ 人工审批 → 幂等写入 → 审计
```

审批必须绑定用户、会话、动作和参数摘要。审批后参数变化时必须重新审批。

## Sandbox 与 Skill

- OpenSandbox 使用非特权用户，限制 CPU、内存、磁盘、进程和执行时长。
- 默认禁止外网，并阻止内网、回环、链路本地和云元数据地址。
- 文件访问限制在允许的沙箱目录，拒绝路径穿越和符号链接逃逸。
- 远程 Skill 必须有白名单来源、固定版本、内容哈希和人工审核。

## 失败策略

上下文提示、技能同步、图表和自动偏好更新可以告警后降级；鉴权、跨用户隔离、订单写入、审批、幂等、审计和持久化一致性必须失败关闭。
